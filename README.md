​My first Godot game :)

I think standard platformers are boring, so why not add some action?

## How to Play
- Go to [Itch page](https://4btu.itch.io/parry-platformer)

OR

- Download the respective zip from [releases tab](https://github.com/Dan5433/parry-platformer/releases)
- Unzip and run:
  - Web: index.html
  - Windows: Parry Platformer.exe

## Controls
- Left, Right: AD or Arrow Keys
- Jump: W, Up Arrow, or Spacebar
- Parry: Left-click
## Parrying
You have a 0.06 second window to parry something before it enters your collision box
